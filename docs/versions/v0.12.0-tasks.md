## Task Breakdown

### Task 1 POV-134: (Completed) Frontend Architecture ADR
- **Description:** Create a formal Architectural Decision Record for the frontend stack. This must define:
  1. Framework choice.
  2. Styling philosophy.
  3. State management strategy.
  4. API client and response envelope handling.
- **Documentation:**
  - `Context`: We need a consistent, production-grade foundation for all future UI work.
  - `Update`: Create `docs/adr/0004-frontend-architecture.md`.
- **Note:** Upon completion of this ADR, the Definition of Done for Task POV-136 must be updated to reflect the chosen technology stack.

### Task 2 POV-135: Monorepo Transition
- **Description:** Restructure the repository to support both Backend and Frontend projects efficiently.
- **Documentation:**
  - `Context`: Decoupled development requires a clear directory hierarchy.
  - `Update`: Move existing code to `/backend`, update Maven root for sub-modules, and adjust CI/CD pipelines.

### Task 3 POV-136: Frontend Project Initialization
- **Description:** Scaffold the frontend application in `/frontend` according to POV-134.
- **Definition of Done:**
  - [ ] React/Vite/TypeScript/Pre-rendering scaffold complete.
  - [ ] TanStack Router (type-safe) and TanStack Query (via Orval) integrated.
  - [ ] Global API Interceptor for `{ data, meta, error }` envelopes and `X-Correlation-ID`/`If-Match` implemented.
  - [ ] OIDC Login flow and basic session state management.
  - [ ] Master Layout (Sidebar/Header) using Tailwind CSS and Shadcn/UI.
  - [ ] Vitest and Playwright base configuration.

### Task 4 POV-137: Dashboard MVP
- **Description:** Implement the first interactive screen fetching data from `GET /api/v1/dashboard`.
- **Definition of Done:**
  - [ ] Dashboard route implemented.
  - [ ] Widgets for active topics and weekly stats rendered.
  - [ ] Recent briefings list displayed with navigation.

### Task 5 POV-138: Real-time Event Stream (SSE)
- **Description:** Integrate the v0.11 SSE stream into the UI to provide live feedback on orchestration jobs.
- **Definition of Done:**
  - [ ] EventSource client implemented in the frontend.
  - [ ] Toast or notification component for "Job Status Changed" events.
  - [ ] Real-time status badges in tables if applicable.

### Task 6 POV-139: Continuous Deployment & Scanning Hardening
- **Description:** Optimize the build and deployment process for the full stack and ensure the new frontend project is integrated into the security pipelines.
- **Definition of Done:**
  - [ ] Multi-stage Dockerfile containing both BE and FE.
  - [ ] Nginx or integrated Quarkus static serving configured for production.
  - [ ] Frontend dependency scanning (Trivy/Snyk) integrated into GitHub Actions.
  - [ ] Update `RUNBOOK.md` with full-stack deployment instructions.

### Task 7 POV-140: Audit Log Admin UI
- **Description:** Build the UI for administrative visibility of technical request logs.
- **Definition of Done:**
  - [ ] Admin shell implemented.
  - [ ] Paginated table for `GET /api/v1/admin/audit-log`.
  - [ ] Search/Filter capabilities for audit entries.
