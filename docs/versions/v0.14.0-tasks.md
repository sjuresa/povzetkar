## Task Breakdown

### Task 1 [POV-153]: (Completed) (UX) Advanced Topic & Source Management
- **Title:** `feat(topic): Implement advanced settings, search-based source selection, and persistent visibility`
- **Description:** 
  Refine Topic Management to be less cluttered but more powerful.
  - **Advanced Toggle**: Prompt template selection should be an "Advanced" setting (collapsed by default).
  - **Persistent Source View**: The Topic Detail/Edit page should only show *currently selected* sources.
  - **Search-Based Addition**: New sources are added to a topic via a search/filter popover from the library, not a bulk list.
  - **Quick Intake**: Integrated flow for adding an entirely new `ContentSource` within the topic context (including metadata enrichment).
- **Context / Documentation:**
  - [../adr/0004-frontend-architecture.md](../adr/0004-frontend-architecture.md)
  - [../analysis/frontend-specification.md](../analysis/frontend-specification.md)
  - [../knowledge/frontend-ux-resilience.md](../knowledge/frontend-ux-resilience.md)
  - [../features/topic-management.md](../features/topic-management.md)
- **Acceptance Criteria:**
  - [x] Topic Form: Prompt template hidden under "Advanced" toggle.
  - [x] Topic Detail/Edit: Only selected sources are listed with clear "Remove" action.
  - [x] Backend: Idempotent source creation logic and metadata enrichment (YouTube) implemented.
  - [x] **test(e2e)**: Verify persistent source list after edit and save.
- **Definition of Done**: Global DoD + Refresh `frontend-specification.md` and `topic-management.md`.
