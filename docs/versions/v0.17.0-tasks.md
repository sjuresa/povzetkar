# Version 0.17.0 Tasks: Administrative Control & User Onboarding

**Version:** 1.1
**Status:** Completed
**Project Task:** POV-183 (Planning)

## Goals

- Establish operational governance via Admin User Management and an explicit Account Activation State Machine.
- Deliver live background job control (restart + audit trail).
- Harden the transcript ingestion pipeline against IP rate-limiting via a multi-provider fallback chain.
- Polish two long-standing UX friction points: external links in new tabs and session expiry auto-redirect.

- **Task 1 [POV-184] (Admin User Management UI):** ~8h [P0]
