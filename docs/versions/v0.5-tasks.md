# Tasks for Version 0.5

This document lists the concrete tasks for migrating the project to version 0.5, based on the roadmap.

---

### **Time Estimation Summary**

This section provides a high-level time estimate for completing all tasks in version 0.5. The estimate assumes one developer with experience in Java, Maven, and Docker.

-   **Task Cluster 1 (Project Conversion & Dependencies):** 2-3 hours
-   **Task Cluster 2 (Environment & DB Configuration):** 3-4 hours
-   **Task Cluster 3 (Data Model Implementation):** 3-4 hours
-   **Task Cluster 4 (Integration Testing):** 4-6 hours

**Total Estimated Time:**
-   **Core Hours (Pessimistic):** 17 hours
-   **Contingency (25%):** ~4 hours
-   **Final Estimate:** **~21 hours** (approx. 3-4 developer days)

### **Task 1 [POV-29]: Convert Project to Quarkus**

**Title:** `feat(build): Convert existing Maven project to Quarkus`

**Description:**
This task covers modifying the `pom.xml` file to officially convert the project into a Quarkus application. This includes adding the Quarkus Bill of Materials (BOM) for dependency management, adding the `quarkus-maven-plugin` for building and running, and preparing the foundation for future Quarkus extensions.

**Acceptance Criteria:**
- `pom.xml` is updated with `quarkus-bom`.
- `quarkus-maven-plugin` is added to the `build` section.
- The project compiles successfully with the command `./mvnw compile`.
- The application can be run in "dev mode" with the command `./mvnw quarkus:dev`.

---

### **Task 2: [POV-30] Add Key Quarkus Dependencies**

**Title:** `feat(deps): Add dependencies for persistence (JPA, JDBC) and configuration`

**Description:**
Key Quarkus extensions need to be added to `pom.xml` to enable working with a database (PostgreSQL), using JPA with Panache for easier entity management, and supporting testing.

**Acceptance Criteria:**
- The `quarkus-hibernate-orm-panache` dependency is added.
- The `quarkus-jdbc-postgresql` dependency is added.
- Testing dependencies are added: `quarkus-junit5` and `quarkus-test-h2` (or preferably `quarkus-test-common` for later use of Testcontainers).

---

### **Task 3: [POV-31] Set Up Local Environment with Docker Compose**

**Title:** `chore(env): Prepare docker-compose.yml for the local development environment`

**Description:**
A `docker-compose.yml` file needs to be created to simplify running the local development environment. The file must define a PostgreSQL service with the `pgvector` extension enabled, which will be crucial in later project phases.

**Acceptance Criteria:**
- A `docker-compose.yml` file exists in the project's root directory.
- The file defines a `postgres` service using the official PostgreSQL image.
- The service is configured with a persistent volume for data storage.
- The environment can be started with the command `docker-compose up -d`.

---

### **Task 4: [POV-32] Configure Database Connection**

**Title:** `chore(config): Configure the Quarkus application for database connection`

**Description:**
The Quarkus application needs to be configured to connect to the PostgreSQL database running in Docker. This involves adding the appropriate settings to `src/main/resources/application.properties`.

**Acceptance Criteria:**
- `application.properties` contains the correct settings for `quarkus.datasource.jdbc.url`, `quarkus.datasource.username`, and `quarkus.datasource.password`.
- Basic Hibernate ORM properties are set (e.g., `quarkus.hibernate-orm.database.generation=drop-and-create` for development).
- The application successfully connects to the database on startup without errors.

---

### **Task 5: [POV-33] Implement Basic JPA Entities**

**Title:** `feat(model): Implement basic JPA entities: Author, ContentItem, Summary`

**Description:**
Based on `04_database_design.md`, the first JPA entities need to be created. For version `v0.5`, we will focus on basic attributes without implementing all relationships. The entities should extend `PanacheEntity` for easier management.

**Acceptance Criteria:**
- The `Author.java` class is created with the `@Entity` annotation and extends `PanacheEntity`.
- The `ContentItem.java` class is created with the same properties.
- The `Summary.java` class is created with the same properties.
- The entities contain basic fields as defined in the diagram (e.g., `name`, `source_url`, `summary_text`).

---

### **Task 6: [POV-34] Prepare a Basic Integration Test**

**Title:** `test(integration): Prepare a basic @QuarkusTest to verify startup and database connection`

**Description:**
A simple integration test needs to be created to verify that the Quarkus application can start successfully and connect to the test database. This test will serve as a foundation for verifying the new architecture's functionality. It is recommended to use Testcontainers for a more realistic test environment.

**Acceptance Criteria:**
- A new test class (e.g., `ApplicationLifecycleTest.java`) is created in `src/test/java`.
- The class is annotated with `@QuarkusTest`.
- The test contains a simple method that confirms the application starts without errors.
- The test runs successfully with the command `./mvnw verify`.
