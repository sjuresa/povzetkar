# i18n String Audit: v0.17.0 (Administrative Control & User Onboarding)

This audit defines the required translation keys for the Version 0.17.0 cycle. Tone is **formal/professional** for admin surfaces (contrast: v0.16.0 onboarding tone was "Osebni asistent"). Slovenian translations follow the technical-administrative register.

---
