# Version 0.13.0 Test Cases: Input Mastery & UX Foundation

**Task Mapping:** POV-145, POV-147, POV-148


## 1. UX Foundation (Global Resilience)

### TC-UX-01: Skeleton Loading Pattern
- **Steps:**
    1. Open the Dashboard.
    2. Observe the loading state before data arrives.
- **Expected:** Animated skeleton placeholders are shown instead of "Loading..." text or empty space.

### TC-UX-02: Global Error Catching
- **Steps:**
    1. Navigate to a non-existent route or simulate a 500 API error.
- **Expected:** The application shows a user-friendly `ErrorPage` with a "Go Back" button, rather than a white screen or raw JSON.

### TC-UX-03: Theme Switching
- **Steps:**
    1. Go to Profile/Settings.
    2. Toggle between Light and Dark mode.
- **Expected:** Colors and glassmorphic effects update globally according to the selected theme.

## 2. Topic & Source Management

### TC-TS-01: Topic Creation with Validation
- **Steps:**
    1. Click "New Topic".
    2. Submit empty form.
    3. Enter valid name and prompt template.
- **Expected:** Zod validation shows errors for empty fields. Upon valid submission, the topic is created and visible in the list.

### TC-TS-02: Source Library Search
- **Steps:**
    1. Navigate to `/sources`.
    2. Type a partial name of an existing source.
- **Expected:** The list filters in real-time to show matching sources.

### TC-TS-03: Source Item Drilldown
- **Steps:**
    1. Click on a specific source in the library.
    2. View the table of items.
- **Expected:** A list of items (e.g., YouTube videos) is shown with date, title, and status (Fetched/Summarized).

## 3. User Identity

### TC-ID-01: Profile Visibility
- **Steps:**
    1. Open the Profile page.
- **Expected:** Correct Name, Email, and Roles are displayed from the `/me` API endpoint.
