### Task 5 [POV-174]: API Optimization — N+1 Problem
- **Priority:** **P1**
- **Title:** `perf(api): implement Join Fetch for Briefing Listing to eliminate N+1 queries`
- **Description:**
  Optimize BriefingApiResource.getBriefings by using left join fetch b.topic in the HQL query. This will reduce backend database round-trips from 21 to 1 for a standard page load.
- **Resilience & Error States**:
  - **LazyInitializationException**: Ensure the Transaction is active during the mapping phase to avoid Hibernate errors.
- **Context / Documentation:**
  - `BriefingApiResource.java`, `BriefingMapper.java`
- **Required Skills**: `@[skills/clean-code]`, `@[skills/api-patterns]`
- **Performance Budget**:
  - **Response Time (Dashboard List)**: Target < 100ms (Current: ~190ms with N+1).
- **Acceptance Criteria:**
  - [ ] HQL query in `getBriefings` includes `left join fetch b.topic`.
  - [ ] SQL logs confirm only 1 query is executed for the listing.

- **Acceptance Criteria:**

  - [ ] `npm run build` shows a measurable reduction in main bundle size.
