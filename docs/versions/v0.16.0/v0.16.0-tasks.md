# Version 0.16.0 Tasks: User Experience Focus

**Version:** 1.0
**Status:** In Progress
**Project Task:** POV-169 (Planning)

## Goals
- Transform the "First Impression" with a gamified onboarding assistant.

## Task Breakdown

### Task 1 [POV-170]: Prompt Cleanup
- **Priority:** **P0**
- **Title:** `style(ai): Strip redundant headings and sections from summary prompt`
- **Description:** 
  Clean AI output of headers that are already provided by the Dashboard UI.
  - Remove `## Daily Briefing for %s [%s]`.
  - Remove `### 6. Sources Analyzed`.
- **Resilience & Error States**:
  - **Prompt Corruption**: If prompt editing causes hallucinations, revert to the v0.15.0 baseline.
- **Context / Documentation:**
  - `summaries_summary_prompt.txt`
- **Required Skills**: `@[skills/clean-code]`
- **Performance Budget**:
  - **Prompt Size**: Reduction by > 50 tokens (clearing redundant UI headers).
- **Acceptance Criteria:**
  - [ ] AI summaries start directly with content items.
  - [ ] No "Sources Analyzed" footer is present.

### Task 2 [POV-171]: Auditory Feedback Framework
- **Priority:** **P0**
- **Title:** `feat(ux): Implement Success/Error/Info audio profile for system notifications`
- **Description:**
  Integrate sensory feedback into the toast notification system.
  - **Assets**: `success.mp3` (Ding), `error.mp3` (Alert), `info.mp3` (Chime).
  - **Logic**: Redundantly trigger audio mount based on toast type.
- **Resilience & Error States**:
  - **Autoplay Blocker**: Fail gracefully (silent) if browser blocks audio context.
  - **Asset Missing**: No console errors if audio file fails to load.
- **Context / Documentation:**
  - [ADR-0006](../../adr/0006-auditory-feedback-framework.md)
- **Required Skills**: `@[skills/frontend-design]`, `@[skills/nextjs-react-expert]`
- **Performance Budget**:
  - **Asset Size**: Total audio assets (Ding+Alert+Chime) < 50KB (MP3, 64kbps).
- **Acceptance Criteria:**
  - [ ] Notification "Success" triggers a short chime.
  - [ ] Background job failure triggers an alert tone.

### Task 3 [POV-172]: Summary Sharing (Resettable UUID)
- **Priority:** **P0**
- **Title:** `feat(share): Implement individual summary sharing with vanity short URLs`
- **Description:**
  Enable secure, public access to single summaries.
  - **Logic**: UUID-based access with resettable salt.
  - **URL Pattern**: Publicly accessible via `/s/{uuid}`.
- **UI Schema (ASCII Mockup)**:
  ```text
  [ Share Summary ]-----------------------------------
  | [x] Enable Public Link                            |
  | URL: http://povzetkar.si/s/6f9d8ef2... [Copy]     |
  |---------------------------------------------------|
  | [ Reset Link ]  (Generates new UUID)              |
  +---------------------------------------------------+
  ```
- **Resilience & Error States**:
  - **Link Expired**: Show "Summary no longer shared" page if UUID is null or changed.
  - **Projection Leak**: Verify restricted DTO excludes owner sensitive data.
- **Context / Documentation:**
  - [ADR-0005](../../adr/0005-summary-public-sharing.md)
  - [../analysis/use_cases.md](../../analysis/use_cases.md) (UC-8)
- **Required Skills**: `@[skills/api-patterns]`, `@[skills/vulnerability-scanner]`
- **Performance Budget**:
  - **LCP (Public Share Page)**: < 1.0s (Simplified DTO projection).
- **Acceptance Criteria:**
  - [ ] Public view is accessible without login.
  - [ ] UI provides immediate "Copy Link" and "Reset" actions.
