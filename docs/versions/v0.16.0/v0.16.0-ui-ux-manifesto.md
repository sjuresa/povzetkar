# UI/UX Manifesto: v0.16.0 (User Experience Focus)

This manifesto defines the visual and interactive standards for the Version 0.16.0 release cycle, transforming the application shell and pages for perfect theme-awareness and sensory feedback.

---

## 1. Visual Strategy: The Semantic Shift
Currently, components use hardcoded Tailwind dark classes (`bg-slate-900/40`, `text-slate-300`). We are migrating to a complete semantic variable system to enable perfect readability in both themes.

### 1.1 Color Palette (The Zinc Baseline)
Consistent with the Landing Page token system.

| Element | Background (Light) | Background (Dark) | hex Code (Base) |
|:---|:---|:---|:---|
| `var(--color-bg-primary)` | `Neutral-50` | `Zinc-950` | `#fafafa` / `#09090b` |
| `var(--color-bg-secondary)` | `Neutral-100` | `Zinc-900` | `#f5f5f5` / `#18181b` |
| `var(--color-text-primary)` | `Neutral-900` | `Zinc-50` | `#171717` / `#fafafa` |
| `var(--color-text-secondary)` | `Neutral-400` | `Zinc-400` | `#a3a3a3` / `#a1a1aa` |
| `var(--color-border)` | `Neutral-200` | `Zinc-800` | `#e5e5e5` / `#27272a` |

### 1.2 Interactive State Strategy (I-2)
- **Toggle Optimistic UI:** Use immediate state changes with immediate color transitions to give the user a feeling of "Instant Automation".
- **Visual Feedback:** All interactive toggles (e.g., share) must use a high-contrast state: `Zinc-950` (Active on Light) / `Zinc-50` (Active on Dark).

---

## 2. Sensory Feedback & Discovery

### 2.1 Auditory Profile (U-2)
The application provides full sensory confirmation for all major categories of system events to create a "Premium SaaS" feel.

-  **Success**: A short "Ding" (<300ms) for briefing completion and successful actions.
-  **Error**: A distinct "Alert" tone for failed background jobs or critical system errors.
-  **Info**: A neutral "Chime" for general system announcements and background tasks completions.

### 2.2 Actionable Experience (I-4)
Toasts are no longer purely informational. If a background job completes, the toast MUST provide a direct primary action:
- **Example:** `Briefing ready. [View Result]` button within the notification.

### 2.3 Gamified Onboarding (U-5, Option C)
A 5-step interactive checklist monitors user progress on the Dashboard.
- **Visuals**: A sleek progress bar (0% -> 100%) showing completion.
- **Micro-tasks**: Each completed task (e.g., creating a topic) triggers a "Completed" state with a success chime (POV-171).
- **Tone**: All instructions are written in the **Slovenian "Osebni asistent"** tone to emphasize assistant-user collaboration.

---

## 3. Global CSS Standards (R-5)
All color properties must support smooth transitions to provide a premium SaaS feel when the user manually toggles the theme.
- **Rule:** `transition-colors duration-300 ease-in-out` must be applied to the layout root and all primary surface components.
