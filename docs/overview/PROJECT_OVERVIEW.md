# Project Overview: Vision, Goals, and Functionality

This document summarizes the key aspects of the Povzetkar project and serves as a quick introduction to its vision, the problems it solves, and its main functionalities.

---

## 1. The Problem We Are Solving

The [`specification.md`](specification.md) document, in its **"Executive Summary"**, clearly defines the problem of information overload. The project is evolving from a tool for summarizing YouTube videos into an advanced platform for collecting and analyzing intelligence data from multiple sources.

## 2. Project Goals

-   **Strategic Goals** are described in [`specification.md`](specification.md). The main goal is to create an automated intelligence platform with advanced AI capabilities (trend analysis, RAG interface).
-   **Tactical Goals** are detailed in [`roadmap.md`](roadmap.md). This document breaks down the path to the final goal into logical, sequential versions (`v0.5`, `v0.6`, `v1.0`...), demonstrating a clear and well-thought-out development strategy. Each version has a precisely defined goal, e.g., `v0.5` is the "architectural skeleton," and `v1.0` is achieving feature parity with the old architecture.

## 3. Core Functionality

These are described most precisely and from a user-centric perspective in the [`../sdlc/01_functional_requirements.md`](../sdlc/01_functional_requirements.md) document. The document uses **User Stories** to clearly define functionalities, such as:

-   **Data Ingestion:** Configuration of sources (YouTube, websites).
-   **Analysis and Reporting:** Generating summaries, sentiment analysis, trend recognition.
-   **Conversational Interface (RAG):** Asking questions in natural language and receiving answers supported by sources.
-   **Content Creation:** Generating drafts for blogs and social media.

## Conclusion

The project documentation is exemplarily prepared and leaves no doubt about **what** you are building, **why** you are building it, and **how** you will achieve it.
