# Retrospective: v0.12.0 (Frontend MVP & Monorepo Foundations)

**Status:** Draft
**Date:** TBD

## Preliminary Notes from Planning
*   **Focus:** Establishing a functional, deployable frontend integrated into a modern monorepo structure.
*   **Process:** Continuing the successful "Frontend Spec -> API Contract" workflow from v0.11.
*   **Architecture Goal:** Locking in UI standards early via ADR-004 to prevent fragmented frontend development.
*   **Security:** Extending automated dependency scanning to the frontend layer and integrating OIDC session management into the SPA.

## 1. What Went Well
*   **Architectural Clarity:** Finalizing ADR-0004 before implementation ensures that all frontend decisions are formally documented.
*   **Pragmatism:** Successfully optimized the SEO strategy (Pre-rendering over Vike) and the Monorepo strategy (side-by-side folders over NPM Workspaces) during the planning phase to minimize "overkill" and maintain simple deployment foundations.
*   **Monorepo Migration (POV-135):** The transition was smooth thanks to the early identification of cross-module resource dependencies (Changelog loading). Standardizing on Maven `-pl` flags maintained compatibility with existing CI/CD.
